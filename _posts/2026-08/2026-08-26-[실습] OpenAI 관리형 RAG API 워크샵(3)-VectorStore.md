이번 실습은 문서를 Vector Store에 저장하고 검색 가능한 지식 기반 시스템을 구축하는 것을 따라해 볼 수 있도록 정리했다. 또한, Retrieval API와 Responses API의 File Search를 직접 사용하며, 검색 결과가 근거 기반 답변으로 연결되는 과정을 단계별로 익힌다. 마지막에는 FastAPI를 활용해 완성된 RAG 시스템을 웹 API 서비스로 구현해 배포한다.
