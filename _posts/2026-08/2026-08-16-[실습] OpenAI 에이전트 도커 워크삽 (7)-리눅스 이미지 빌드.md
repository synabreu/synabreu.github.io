지난벌 실습에서는 Dockerfile 과 docker-compose.yml 파일을 분석했다. 이번에는 실제로 윈도우 환경에서 리눅스 이미지 빌드하는 실습을 해보겠다.

# 1. 실습 8 - 윈도우 환경에서 리눅스 이미지 빌드

리눅스 이미지 빌드도 파워셀에서 쉽게 실행하도록 아래와 같이 만들었다.

```powershell
.\scripts\build-image.ps1
```

build-image.ps1 파일의 내부를 분석하면 다음과 같다.

```powershell
# PowerShell 명령 실행 중 오류가 발생하면 스크립트를 즉시 중단하도록 설정한다.
$ErrorActionPreference = "Stop"


# 현재 디렉터리의 Dockerfile을 사용하여 Docker 이미지를 빌드한다.
#
# --platform linux/amd64:
# Linux 운영체제와 AMD64(x86-64) CPU 아키텍처용 이미지를 빌드한다.
#
# -t openai-agents-workshop:1.0:
# 이미지 이름을 openai-agents-workshop으로 지정하고 이미지 태그를 1.0으로 지정한다.
#
# 마지막의 점(.)은 현재 디렉터리를 Docker 빌드 컨텍스트로 사용한다는 의미이다.
docker build `
    --platform linux/amd64 `
    -t openai-agents-workshop:1.0 `
    .


# 빌드된 Docker 이미지의 상세 정보를 조회한다.
#
# openai-agents-workshop:1.0:
# 검사할 이미지의 이름과 태그이다.
#
# --format:
# 전체 이미지 정보 중 운영체제와 CPU 아키텍처만 출력하도록 지정한다.
#
# {{.Os}}:
# 이미지가 사용하는 운영체제를 출력한다.
#
# {{.Architecture}}:
# 이미지가 지원하는 CPU 아키텍처를 출력한다.
docker image inspect `
    openai-agents-workshop:1.0 `
    --format '{{.Os}}/{{.Architecture}}'
```

또는 수동으로 리눅스 빌드하는 명령은 다음과 같다. 쉘 스크립트 내부에 아래와 똑같이 실행한다.

```powershell
docker build --platform linux/amd64 -t openai-agents-workshop:1.0 .
```

그리고 나서 리눅스 이미지가 잘 빌드되었는 지 확인하는 것은 다음과 같이 하면된다.

```powershell
docker images openai-agents-workshop
```

운영체제 및 아키텍처를 확인할 수 있는 데 그 명령은 다음과 같다.

```powershell
docker image inspect openai-agents-workshop:1.0 --format '{{.Os}}/{{.Architecture}}'
```

그러면 build-image.ps1 파일을 실행하거나 수동적으로 하나씩 명령을 하거나 예상 결과는 다음과 같다.

```text
linux/amd64
```

즉, 개발 PC의 운영체제가 Windows라고 해서 image가 Windows image가 되는 것이 아니다.
